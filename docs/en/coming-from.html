Words that are only Ultraman's #

  • Pipeline: a flow of visible steps; the same file is a functional test, a load scenario and a CI check.
  • Block: a reusable piece of a pipeline (a login).
  • Verdict: the report's sentence: it held, it queued, it broke, or limited when your computer was the limit.
  • Linked copy: a collection request inside a pipeline that remembers where it came from.
  • Consent: your explicit yes before Ultraman sends something sensitive somewhere new: a secret to a host it never went to, or a file from outside the project. Ultraman asks once per case and sends nothing until you answer (Security and consent).
  • Trusted folder: a project folder you told Ultraman to trust, on this machine. In a folder you haven't trusted it sends nothing from the window and runs no git (trusted folders).
  • Vault: the encrypted store on your computer where secrets live, opened with your master password and never placed in the repo (the vault).

What keeps you safe #

  • You: nothing is converted into code that runs: scripts from Postman, JMeter or Artillery are listed as "needs a hand" and never executed (importing).
  • You: imported secret values never land in a file; they go to the vault or are left for you to set (the vault).
  • Your team: what you bring in becomes YAML in git, so reviewers see it as a diff.
