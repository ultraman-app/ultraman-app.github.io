Si vienes de otra herramienta #

Algunas ideas se llaman igual aquí, otras tienen otro nombre y unas pocas no existen a propósito.

Streams #

HerramientaUltraman
La request WebSocket de Postmanuna request de stream en el área Requests (Nuevo WebSocket o SSE)
Los mensajes guardados de Postmanla pestaña Mensajes de la request
k6 ws.connect, socket.on('message')un paso websocket y un receive
El engine ws de Artillery: connect, sendun paso websocket y un paso send
Gatling ws("x").connect, await(...).on(check)lo mismo: websocket, receive con where

No incluye: reconexiones automáticas (vuelve a conectar o escribe el reintento como pasos), Socket.IO, compresión de WebSocket ni un mock para streams.

Palabras que son solo de Ultraman #

  • Pipeline: un flujo de pasos visibles; el mismo archivo sirve como prueba funcional, como escenario de carga y como check de CI.
  • Bloque: una pieza reutilizable de una pipeline (por ejemplo, un login).
  • Veredicto: la frase que resume el reporte: aguantó, encoló, se rompió, o limited cuando el límite fue tu computadora.
  • Copia vinculada: una request de una colección dentro de una pipeline que recuerda de dónde viene.
  • Consentimiento: tu sí explícito antes de que Ultraman envíe algo sensible a un lugar nuevo: un secreto a un host al que nunca ha ido, o un archivo de fuera del proyecto. Ultraman pregunta una vez por caso y no envía nada hasta que respondes (Seguridad y consentimiento).
  • Carpeta de confianza: una carpeta de proyecto en la que le indicaste a Ultraman que confíe, en esta máquina. En una carpeta en la que no has confiado, no envía nada desde la ventana ni ejecuta git (carpetas de confianza).
  • Bóveda: el almacén cifrado de tu computadora donde se guardan los secretos; se abre con tu contraseña maestra y nunca se incluye en el repo (la bóveda).

Qué te mantiene a salvo #

  • Tú: nada se convierte en código ejecutable: los scripts de Postman, JMeter o Artillery aparecen en la lista como "Hay que terminarlo a mano" y nunca se ejecutan (importar).
  • Tú: los valores secretos importados nunca terminan en un archivo; van a la bóveda o quedan pendientes para que los definas tú (la bóveda).
  • Tu equipo: lo que traes se convierte en YAML dentro de git, así que quienes revisan lo ven como un diff.
