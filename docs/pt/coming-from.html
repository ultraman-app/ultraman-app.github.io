Palavras que só existem no Ultraman #

  • Pipeline: um fluxo de passos visíveis; o mesmo arquivo serve de teste funcional, de cenário de carga e de verificação no CI.
  • Bloco: um pedaço reutilizável de pipeline (um login, por exemplo).
  • Veredito: a frase do relatório: aguentou, enfileirou, quebrou, ou limited quando o limite foi o seu computador.
  • Cópia vinculada: uma request de coleção dentro de uma pipeline que lembra de onde veio.
  • Consentimento: o seu sim explícito antes de o Ultraman enviar algo sensível para um lugar novo: um segredo para um host aonde ele nunca foi, ou um arquivo de fora do projeto. O Ultraman pergunta uma vez para cada caso e não envia nada até você responder (Segurança e consentimento).
  • Pasta confiável: uma pasta de projeto em que você disse ao Ultraman para confiar, nesta máquina. Numa pasta em que você não confiou, ele não envia nada pela janela e não executa git (pastas confiáveis).
  • Cofre: o armazenamento criptografado no seu computador onde ficam os segredos; ele abre com a sua senha mestra e nunca vai para o repositório (o cofre).

O que mantém você seguro #

  • Você: nada vira código executável: scripts do Postman, do JMeter ou do Artillery aparecem listados em "Precisa de ajuste manual" e nunca são executados (importar).
  • Você: valores secretos importados nunca vão parar num arquivo; vão para o cofre ou ficam para você definir (o cofre).
  • Sua equipe: o que você traz vira YAML no git, então quem revisa vê tudo como um diff.
